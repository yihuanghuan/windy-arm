# 新机械臂 ARM6 familiarization 实机记录

分支 lagrange-smc；本轮未修改控制代码或参数。第一次故障后仅在操作者明确指示继续后进行第二次启动。第二次故障后未自动重试。

## 1. Readonly
新启动 readonly 403 帧/约4秒，100.405 Hz，只有 joint1…joint6。256 组 TF/FK 数值一致。操作者确认六轴真实运动与 RViz 的轴、方向和变化一致；腕部阻力较大，只做轻微转动。J6 未取得完整 5–15° 定量扫描，因此不声称该幅度的全轴量测验收。RViz/TF base_link→link6 来自真实反馈。

## 2. 历史成功依据及差异
见 [KNOWN-GOOD VS CURRENT](KNOWN_GOOD_VS_CURRENT.md)。历史文档记录 kp=0 不下坠，但缺少成功运行的精确模型/参数快照；旧脚本 ratio 与已校准URDF文档矛盾，不作为重复修正依据。当前显式offset=0，g_urdf(q+offset)，无ratio/alpha重乘，无重复阻尼。保留所有安全保护。

## 6–7. 手推与 HARD_ABORT
Run01 操作者确认在故障前人工推动，故障后没有下坠。Run02 操作者确认当时正在推动 J1，故障后没有下坠。随后补充已推动除J6外各轴，阻力较大且基本回原位；但日志显示Run02有效GUIDE期间只有J1明显运动，随即fault。故障后的PD保持Kp=[30,30,30,5,5,5]，目标为故障时捕获的位置，确实会产生位置恢复力。因此上述后续手感不构成GUIDE低阻抗验收，也不能据此直接修改GUIDE阻尼。六轴缓推/松手停止/不回旧位尚未完成，不能宣布手推验收通过。

## 8. Fault fallback
两次实机实际串口写入均核对帧长度、校验和、六轴映射和ghost slot=0；分别核对2093及3897批命令。

- Run01: 故障hold FF = [0.149088, -2.149075, 1.029213, -0.001918, 0.000000, 0.000119] Nm；超速轴FF清零，其余保留最后实际有界支撑；故障后2秒 delta q = [-0.000381, 0.000000, 0.000000, -0.000383, -0.008439, 0.000000] rad。
- Run02: 故障hold FF = [0.000000, -2.180013, 1.019545, -0.007336, 0.005857, 0.000127] Nm；超速轴FF清零，其余保留最后实际有界支撑；故障后2秒 delta q = [-0.027848, 0.000000, 0.000000, 0.000000, 0.000000, 0.000000] rad。

J2/J3两次故障后2秒编码器均未变化。Run01和Run02现场均明确确认无下坠。完全无效反馈导致all FF=0的分支未人为制造硬件故障验证，仍只有离线/伪串口证据。当前driver维持故障锁存PD hold和其余轴FF，GUIDE已退出，RViz仍运行；未宣称电机失能。
