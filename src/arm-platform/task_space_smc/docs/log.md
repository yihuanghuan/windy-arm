## 附：保持任务 QP 的设计论证

以下原文出自 `core/task_qp.py` 与 `core/dense_qp.py` 的模块 docstring，
2026-08-06 注释整理时从代码移出。它们是**设计理由**，不是公式也不是功能，
按规则不留在代码里；但其中的实测数据是当初做出这些选择的依据，故完整保留于此。

### 一、为什么力矩箱是硬的、加速度箱是软的

这套 QP 取代的是「无约束解 `qdd` → 跑 RNEA → 后端把力矩削到限幅」这条链路。
后端截断正是抖振的来源：控制器算出一个不许发的力矩，适配器把它削掉，下一拍控制器
——它从来不知道自己被削过——再要一次同样的东西。

整个形式化建立在一个结构性事实上：**RNEA 对关节加速度是仿射的**，而它的两个分量
每拍本来就要算。

```
tau(qdd) = c + M qdd
  c = tau_bias + tau_friction_feedforward   (qdd = 0 的 RNEA，加上与 qdd 无关的静摩擦项)
  M = 质量阵的手臂分块
```

所以力矩上限是 `qdd` 的**线性**约束，属于求解器内部而不是解完之后。因为 `M` 可逆，
这个关系双向成立，于是问题实际是**以力矩为决策变量**求解的。

**决策变量**：`tau (n)`，解完再取 `qdd = M^-1 (tau - c)`。

**优先级（高到低）**：

1. 力矩 + 力矩变化率 —— 决策变量上的**硬**箱
2. 末端位置 —— `w_position`
3. 末端姿态 —— `w_orientation`（不可行时先让这一项）
4. `qdd` 箱 —— 弹性（速度包线、限位制动、加速度上限），`w_qdd_box_slack`
5. 回中 / 限位规避 / 平滑

**哪个箱是硬的，为什么是这一个。** 看起来更自然的安排——加速度箱硬、力矩弹性——是
错的，而且错得可测量。贴近关节限位且带着非零速度时，制动约束要求一个额定力矩产生
不了的减速度。加速度箱设为硬约束时，求解器如实满足了它，于是要出**超过额定上限
2.4 N·m** 的力矩，接着被适配器削掉——这恰恰是本模块要消灭的后端截断。

额定力矩是物理事实；速度包线与制动距离是策略。所以力矩是硬箱，加速度箱带一个很大的
权重做弹性：两者相容时包线被严格遵守，真冲突时包线让步，而那是唯一物理上可用的答案。
关节速度看门狗不变，仍独立守着包线。

可行性于是变成平凡的而非需要论证的：力矩箱按构造是非空区间，且每个 `tau` 都映射到
某个 `qdd`，所以可行集永不为空，求解器在 200 Hz 下不会硬失败。

### 二、为什么用加权而不是字典序（分层）

严格凸 QP 有唯一极小点，而这个唯一极小点是代价与边界的分片仿射、局部 Lipschitz
函数。因此状态的小变化只产生指令的小变化——**包括跨活跃集切换时**——这就是白拿到的
抗抖振保证。

字典序求解每一层要一个 QP，外加每层一个 epsilon 松弛（epsilon 不过是戴了帽子的权重），
而且当第一层的最优面维数变化时，第二层的解会真的跳变——正是要去掉的那种行为。

### 三、加速度箱为什么是「裁入」而不是「取交集」

加速度上限是**裁进**速度/位置箱，而不是与之取交集。两条理由都承重：

* 这样 `lo <= hi` 无条件成立，QP 永远拿不到空箱
  （`_feasible_acceleration_box` 已经自行保证了 `lo_v <= hi_v`）。
* 当 `qd` 已经越出包线时，恢复用的加速度幅值可以合法地超过 `qdd_max`，
  取交集会禁掉制动——等于告诉臂它不许减速。

### 四、力矩箱为什么先把 `tau_prev` 裁进额定箱

不是为了好看：这是让 `lo <= hi` 按构造成立的原因。如果上一拍的指令不知怎么落在
额定箱外，未经裁剪的中心会把整个变化率窗口放到箱外，产生空区间。

`tau_prev` 必须是**适配器实际发出**的值，且调用方必须复现适配器在指令超时后把它
清零的规则。两边对变化率基准的理解一旦不一致，适配器就会削掉一条 QP 认为合法的指令
——那正是本模块要消除的后端截断。

### 五、任务加速度为什么要先限幅

保持剖面的等效位置增益是 `k * lambda = 8 * 18 = 144` /m，所以 5 cm 的误差要求
7.2 m/s²——远超臂能产生的量。把这个需求直接喂给 QP，正是残差爆掉、解被钉在约束边界上
的原因，而那里就是 bang-bang 行为的来源。

整体缩放（而不是逐轴截断）保持指令方向不变，末端沿指令直线滞后，而不是偏离它。

### 六、稠密 QP 求解器：为什么是 Goldfarb-Idnani 对偶主动集法

`H` 必须对称正定。全部用稠密 numpy；没有 scipy 也没有外部求解器，因为本机没装
`quadprog` / `osqp` / `qpsolvers` / `cvxpy` / `proxsuite` 中的任何一个，而 200 Hz
的实物回路也不适合临时引入。

选这个算法的理由：

* 它从**无约束**极小点出发，一次加一条约束，所以不需要 Phase 1，也不需要可行性恢复。
* 每次迭代对偶目标严格上升，配合最小下标破平局就不会循环。至多 `n` 条约束可以活跃，
  迭代次数因此有界。
* 逐位确定：无随机数、无自适应容差、不依赖计时。同样的输入每次都给出同样的输出，
  这才使得行为可测试。

严格凸的要求不是附带的。正定 Hessian 使极小点唯一，而 QP 的唯一极小点是 `g` 与 `d`
的分片仿射、局部 Lipschitz 函数。这个连续性**就是**调用方买到的抗抖振保证。

### 七、为什么用 Cholesky 而不是 `np.linalg.cond`

`_spd_solve` 里 Cholesky 兼作条件数判据：`S` 是正定阵的 Schur 补，恰好在活跃行线性
相关时分解失败。用它而不是 `np.linalg.cond`，把一次 SVD 挡在每轮迭代之外——
仅此一项就把最坏情况的求解从 **2.8 ms 降到 1 ms 以内**。

### 八、为什么经 Cholesky 因子施加 `H^-1` 而不是显式求逆

保持任务的 QP 是**故意**病态的：位置/姿态 1e4:1 的权重差就是任务优先级本身，
松弛权重再压几个数量级，于是 `cond(H)` 落在 5e7 左右。在这个条件数下显式构造 `H^-1`
大约丢八位有效数字，误差再沿主动集步累积，直到「等式」行被明显违反——实测出现过
**求解器报 `optimal`、而某条力矩行差了 14.7 N·m**。三角回代把误差压在分解本身的量级。

同理，每轮由工作集重建迭代点（`_kkt_point`）而不是累加 `z += t*dz`：在 `cond(H) ~ 5e7`
下累加形式会漂到把已违反的约束报成最优。

### 九、为什么另起一个 `solve_box_penalty_qp`，而不是用通用的 `solve_qp`

把一个变量上下界写成 `+e_i · x >= lo` 与 `-e_i · x >= -hi` 两行，就给了主动集法一对
**严格线性相关**的法向量。关节已越出速度包线时加速度箱塌成（几乎）一个点，两行同时
贴在边界上，对偶主动集法每轮迭代都要处理这个相关性。在真实问题形状上实测：
**3000 个对抗算例中有 2870 个从 `solve_qp` 返回 `infeasible`**，而弹性形式下它们按构造
全都可行。

把上下界当**箱**、用投影处理，这个失效模式整个消失。再把松弛变量解析消去，剩下一个
凸的、C1 的、带箱约束的分片二次函数：

```
F(x) = 1/2 x'Hx + g'x + 1/2 sum_i w_i v_i(x)^2 ,   x in [lo, hi]
v_i(x) = (A x + a0) 第 i 行超出 [rlo_i, rhi_i] 的量
```

`v` 在拐点处为零，故 `F` 连续可微，投影（半光滑）牛顿迭代全局收敛。松弛只取 L2：
L1 是经典的精确罚，但会在 `v = 0` 处留一个梯度跳变，正好毁掉这里赖以稳健的光滑性。
取 `w = 1e6` 时残余违反量约为 `约束力/w ~ 1e-5 N·m`，对 9 N·m 的限幅在调用方的任何
用途下都可视为精确。

### 十、为什么用精确线搜索而不是 Armijo 回溯

沿一条直线，目标是一维凸分片二次函数，其导数分片线性且单调不减，故极小点有闭式解：
把各行进出自己箱子的 alpha 收集为断点，一次性算出所有断点处的导数，在导数变号的那一段
内插值。

这取代了 Armijo 回溯。只要求「有下降」会让迭代之字形往返：在接近生产的序列上实测
**平均 7.3 次、最坏 60 次外层迭代，第 95 百分位求解 5.2 ms，而预算是 5 ms**。
精确步消掉了这个往返。

### 十一、收敛判据为什么取相对值

任务权重 1e4 乘上 O(10) 的需求，梯度天然在 1e5~1e6 量级，用绝对阈值等于要求把最后
几位十进制也磨平——实测那会让 **2000 个已收敛算例中的 1403 个**被报成 `max_iter`。

### 十二、零宽箱为什么要展宽 1e-6

关节已越出速度包线时，箱塌成一个点（那唯一允许的制动加速度）。零宽箱使上下界两行
成为严格的等式对，即线性相关，而这正是主动集法唯一真正难处理的输入形状。
展宽 1e-6 rad/s² 消掉退化，且远低于臂能分辨的量级。
